### ✦ &nbsp; PROJECT SPOTLIGHT

**[PassGuard](https://github.com/Ka1nnnn/passguard)** &nbsp; / &nbsp; Privacy-friendly password tools for your browser.

Check password strength, generate passwords and look up email breaches. Password breach checks use k-anonymity; email checks send the address to a third-party service. Available in English, Russian and Chinese.

`JavaScript` &nbsp; `HTML / CSS` &nbsp; `No build step`
